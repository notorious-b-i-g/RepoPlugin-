# RepoAgentExtended

Мод BepInEx для игры **R.E.P.O.**, который транслирует наблюдения (observations) локального игрока по UDP. Телеметрический мост для ИИ/RL-агента.

## О проекте

`RepoAgentExtended` — исследовательский инструмент для обучения с подкреплением (RL) и ИИ-агентов на базе игры R.E.P.O. (Steam).

Плагин подключается к процессу игры через BepInEx, на каждом кадре находит локального игрока (по `photonView.IsMine`) и с фиксированной частотой собирает вектор наблюдения о его состоянии и ближайшем окружении. Полученные данные сериализуются в JSON и отправляются UDP-датаграммами на локальный сокет, откуда их может читать внешний агент (например, на Python) для построения политики, инференса или сбора датасета.

Часть данных игры недоступна напрямую, поэтому приватные поля (`health`/`maxHealth`, `roomVolumeCheck` и др.) читаются через рефлексию.

## Стек

- **Язык:** C# (LangVersion 9.0)
- **Платформа:** .NET Framework 4.8
- **Загрузчик модов:** BepInEx 5.4 (+ HarmonyX)
- **Движок:** Unity, сетевой слой Photon PUN (`PhotonUnityNetworking`)
- **Доступ к данным игры:** рефлексия (`System.Reflection`) для чтения приватных полей
- **Транспорт телеметрии:** `System.Net.Sockets.UdpClient`
- **Сериализация:** `UnityEngine.JsonUtility` (JSON)

## Что стримится по UDP

Состояние упаковывается в объект `Obs`, сериализуется в JSON и отправляется датаграммой.

- **Транспорт:** UDP, по умолчанию `host = 127.0.0.1`, `port = 5555`
- **Частота:** 10 Гц (`SEND_HZ`)
- **Формат:** UTF-8 JSON, одна датаграмма на одно наблюдение

Поля объекта `Obs`:

| Поле | Тип | Описание |
| --- | --- | --- |
| `pos_x`, `pos_z` | float | Позиция игрока в мире по осям X и Z |
| `yaw_sin`, `yaw_cos` | float | Ориентация (рыскание) в виде синуса и косинуса угла |
| `vel_f`, `vel_s`, `vel_up` | float | Скорость: вперёд, вбок и вертикальная (проекции на оси игрока) |
| `grounded` | bool | Находится ли игрок на земле |
| `hp_norm` | float | Здоровье, нормированное в диапазон [0, 1] |
| `stamina_norm` | float | Стамина, нормированная в диапазон [0, 1] |
| `ray[16]` | float[] | 16 «лидарных» лучей-рейкастов: 8 направлений (0–315° с шагом 45°) на двух высотах (колено и грудь). Значение — дистанция до препятствия, максимум `RAY_LEN = 3` м |
| `delta_hp` | int | Изменение здоровья с предыдущего кадра наблюдения |
| `item_count` | int | Количество переданных координат предметов |
| `item_pos` | ItemPos[] | Координаты `{x, y, z}` ближайших предметов (приоритетно — из тех же комнат, что и игрок; до `MAX_ITEMS = 128`) |

## Сборка и установка

### Требования

- Установленная игра R.E.P.O. с предварительно настроенным BepInEx 5.4
- .NET Framework 4.8 SDK и MSBuild (Visual Studio или Build Tools)

### Игровые DLL

Для сборки нужны сборки из самой игры и BepInEx (`Assembly-CSharp.dll`, `UnityEngine*.dll`, `PhotonUnityNetworking.dll`, `BepInEx.dll` и т. п.). Скопируйте их из каталога установки игры в папку `libs/` репозитория:

- `<Steam>/steamapps/common/REPO/REPO_Data/Managed/*.dll`
- `<Steam>/steamapps/common/REPO/BepInEx/core/BepInEx.dll`

При необходимости поправьте пути `HintPath` в `HelloRepoPlugin/HelloRepoPlugin.csproj`, чтобы они указывали на `libs/` (NuGet-зависимости, например MessagePack, восстанавливаются автоматически).

### Сборка

```bash
msbuild HelloRepoPlugin/HelloRepoPlugin.csproj /p:Configuration=Release
```

Собранная сборка появится в `HelloRepoPlugin/bin/Release/`.

### Установка

Скопируйте полученный `HelloRepoPlugin.dll` в каталог плагинов BepInEx:

```
<Steam>/steamapps/common/REPO/BepInEx/plugins/
```

Запустите игру. В логах BepInEx появится строка `[RepoAgentExtended] Init OK`, а при входе в игру за локального игрока — `[Agent] → STREAM ON`. После этого наблюдения начнут передаваться на `127.0.0.1:5555`.
